# Painel-de-ideias-PTAC
## Descrição
Este projeto foi desenvolvido em React como atividade da disciplina.
O sistema permite:

- Adicionar uma ideia;
- Marcar uma ideia como concluída;
- Remover uma ideia;
- Limpar as ideias concluídas;
- Mostrar a quantidade de ideias.

## Tecnologias utilizadas
- React
- JavaScript
- CSS
